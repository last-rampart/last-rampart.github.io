Signaler un problème

Le jeu a planté, une règle ne fait pas ce qu'elle dit, un texte est faux ? Dites-le-nous ici. Seule la première case est obligatoire ; le reste nous aide à retrouver le problème.

L'envoi crée un signalement sur GitHub, notre outil de suivi : il vous faut un compte GitHub (gratuit, à créer en une minute si on vous le demande). Votre signalement y est public. Sans compte, ou pour rester discret, écrivez-nous.

Et ce que vous attendiez à la place.

Les étapes, si vous les connaissez. Vous pourrez joindre une capture d'écran sur GitHub.

Le téléphone et sa version d'Android, ou le navigateur.

Si vous la connaissez : le rapport d'erreur la donne, la fiche Play Store aussi.

Si le jeu a affiché « Un problème est survenu », collez ses détails. Les dernières erreurs sont aussi dans Réglages › Erreurs › Copier.

GitHub vous montre le signalement rempli ; vous le relisez, puis vous l'envoyez.
